# FC Talblick – GitHub Pages

## Veröffentlichung
1. Alle Dateien dieses Ordners in ein GitHub-Repository hochladen.
2. GitHub → **Settings → Pages**.
3. Unter **Build and deployment** „Deploy from a branch“ wählen.
4. Branch `main` und Ordner `/ (root)` auswählen.
5. Speichern.

Die Seite ist als statische GitHub-Pages-Seite gebaut und benötigt keinen Server.

## Bewerbung
Das Formular öffnet per `mailto:` das E-Mail-Programm des Besuchers und adressiert die Bewerbung an:

ESportTalblick@gmail.com

Wenn ein Besucher kein E-Mail-Programm eingerichtet hat, kann das Formular nicht direkt versenden. Für echte serverseitige Formulare kann später z. B. Formspree oder ein eigener Backend-Dienst eingebaut werden.
